# 系统当前状态

更新时间：2026-08-23

## 总体阶段

项目处于阶段一设备通信与抽象层 PoC。尚未进入完整视觉算法、产品跟踪、正式 WPF UI 或生产部署阶段。

## 已完成

- .NET 8 x64 解决方案与分层基础。
- PLC 抽象、Siemens S7.NetPlus 驱动、50 ms 轮询、命令脉冲与断线重连。
- PLC 状态多变量批量读取、连接参数/点位静态校验和 PLC 设备身份。
- PLC V1 协议版本检查、可配置命令流水号应答、双向心跳监控，以及业务拒绝/通信故障分流。
- PLC 模拟器支持命令延时、业务拒绝和命令网络故障注入；协议测试扩展到 16 项。
- DB100/DB101 通信点表 V1、TIA V18 DB 外部源和创建/导出指南；C# 默认地址已与 V1 对齐。
- 已连接真实 TIA V18 工程并核对 PLC_1、DB100、DB101；两个通信 DB 均为 Standard 布局且块号为 100/101。
- 已实现并导入 `FB_UpperComputerCommunication`、专用实例 DB 和 SCL `Main (OB1)` 调用，PLC 完整编译为 0 错误、0 警告。
- PLC 侧已具备协议版本校验、双向心跳、命令上升沿、流水号去重、Busy/Error/Status 和完成后应答逻辑。
- 相机抽象：配置、采集状态、异步帧流、FrameId、ProductId、池化缓冲区生命周期。
- 运动控制器抽象：使能、回零、绝对/速度运动、停止、位置读取和硬件位置比较计划。
- 机械臂抽象：状态、复位、伺服、程序选择、启动、停止和回原点。
- PLC、相机、运动控制器和机械臂模拟器。
- 设备抽象与异常恢复的自动化测试。
- 现有 C# 方法中文 XML 注释整改，以及自动注释检查和 GitHub Actions 流程。
- 01→18 顺序开发路线图。

- 六相机并行视觉管线、ProductID 跟踪、Reject、MES、数据持久化和 WPF UI。

## 安全边界

- 相机触发和 NG 剔除时序必须在运动控制器内通过编码器位置比较完成。
- 急停、安全门和 STO 必须由安全继电器或安全 PLC 完成。
- 上位机和机械臂接口不得绕过控制柜安全条件或自动恢复生产运行。
